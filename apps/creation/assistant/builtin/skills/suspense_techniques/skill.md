# 悬念设计

## 悬念类型（按强度排序）
1. **生死危机**：主角面临即时危险（最强，慎用，每3-5集一次）
2. **身份揭穿**：秘密即将曝光（"她就是当年的..."）
3. **两难抉择**：主角被迫二选一，结局未明
4. **意外反转**：观众预期被打破
5. **信息缺口**：抛出未答问题（"那份文件去哪了？"）

## 集尾钩子公式
- 反转 + 定格：真相揭露瞬间切走
- 危机 + 黑屏：危险降临不给结果
- 承诺 + 打断：即将得到答案被打断

## 常见错误
- 悬念过早揭晓（下集开头3分钟内解决=浪费）
- 悬念与主线无关（为悬念而悬念）
- 同类型悬念连用（观众疲劳）

## 工作流程
检查每集结尾 → 标注悬念类型与强度 → 弱钩子用 propose_edit 改写结尾3-5句台词或加新场景
