# 剧情反转设计

## 好反转的标准
意料之外 + 情理之中：回看时有伏笔，揭晓时不突兀。

## 反转类型库
1. **身份反转**：受害者其实是加害者/穷小子是豪门继承人
2. **动机反转**：帮助主角的人另有所图
3. **认知反转**：观众和主角都误会了（"坏人"其实在保护她）
4. **时间反转**：以为的顺序是错的（葬礼在婚礼前）
5. **双重反转**：反转之上再反转（A假死→其实真死→但留了后手）

## 伏笔埋设原则
- 提前3-5集埋，至少2处不同形式的线索
- 伏笔要"当时无感，回看恍然"（避免一眼看穿）
- 揭晓时用闪回串起所有伏笔（观众自己拼图更爽）

## 检验问题
- 反转后角色动机是否还成立？
- 是否与已确认事实矛盾？（用 get_episode 核对）
- 爽点是否值得反转的复杂度？（短剧优先情绪冲击非烧脑）

## 工作流程
确定反转位置（建议集尾或中点）→ 检查现有伏笔 → propose_edit 补伏笔场景 + 改写揭晓场景
