# 角色声音一致性

## 声音档案要素
为每个主要角色建立语言指纹：
- **句式**：短句爆发型 / 长句铺垫型 / 反问型
- **词汇**：口头禅、禁用词（霸总不说"随便"）
- **情绪表达**：直接宣泄 / 隐忍克制 / 阴阳怪气
- **关系变体**：对上级/平级/下级的语气差异

## 检查清单
1. 该角色的台词换给另一角色是否违和？
2. 情绪激动的戏是否保持了角色的表达方式（霸总愤怒≠摔东西，可能是冷暴力）？
3. 跨集人设是否漂移（第1集高冷 vs 第10集话痨无过渡）？

## 修复手法
- 提取角色3-5句代表性台词作为"声音锚点"
- 违和台词按锚点句式改写，保留信息量
- 人设漂移处加过渡戏（解释性格变化的触发事件）

## 工作流程
list_characters → get_character 取设定 → 抽样各集场景比对 → propose_edit 修违和台词
