# 短剧节奏分析

## 适用场景
用户反馈某集"太慢"、"拖沓"、"看不下去"，或要求检查节奏。

## 分析框架

### 1. 量化指标
- **场景时长分布**：单场景超过90秒需标记
- **冲突密度**：每集应有≥3个冲突点或信息增量
- **钩子位置**：开头30秒内必须有钩子，结尾必须有悬念

### 2. 节奏诊断清单
1. 开头是否超过45秒才进入主线？
2. 是否存在连续2个以上"过渡场景"（无冲突无信息）？
3. 对白是否承载剧情推进，还是纯寒暄？
4. 结尾悬念强度是否足以驱动下一集？

### 3. 修改手法
- **删减**：合并功能重复的过渡场景
- **前置**：把冲突/反转前移，删掉慢铺垫
- **打断**：长对白用动作/打断切碎
- **加钩**：场景结尾补一个未解问题

## 输出格式
先用 get_episode + list_scenes 收集数据，逐场景标注节奏评级（紧凑/正常/拖沓），再用 propose_edit 提交修改提案，summary 中说明"删/并/移"哪个场景、预计节省时长。
