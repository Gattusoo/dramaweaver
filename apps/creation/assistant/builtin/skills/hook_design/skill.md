# 开场钩子设计

## 数据基准
- 前3秒决定去留，前30秒决定追看
- 第1集开头必须是全剧最强钩子之一

## 钩子公式（按优先级）
1. **冲突先行**：开场即争吵/追逐/对峙（"你敢动她一下试试！"）
2. **反常画面**：违背预期的视觉（新娘在葬礼上笑）
3. **悬念台词**：抛出无法忽略的问题（"杀死我女儿的人，就在这个房间"）
4. **高潮倒叙**：先给结局最炸一幕，再"48小时前"
5. **身份冲击**：开场亮出反差身份（外卖小哥掏出黑卡）

## 禁忌
- 慢镜头风景/日常开场
- 自我介绍式旁白（"我叫林晚，一个普通女孩"）
- 先铺垫世界观再进剧情

## 工作流程
get_episode 看第1集前3场 → 判断当前钩子类型与强度 → 弱则用 propose_edit 重写开场（优先把后文冲突前移）
