# 对白打磨

## 诊断维度
1. **口语化**：删除书面语（"然而""因此"→"可是""所以"），短句优先
2. **辨识度**：遮住角色名能否猜出是谁说的？每角色应有口头禅/句式偏好
3. **潜台词**：直白表达→留白暗示（"我恨你"→行动或反话）
4. **信息效率**：每句对白应推进剧情或揭示性格，否则删

## 打磨手法
- 长句拆短：超过25字的对白优先拆分
- 加口语词：呢/吧/啊/嘛/呗，但每角色风格统一
- 冲突升级：平铺直叙的回答→带情绪的反击/回避
- 删敬语：亲密关系中删除"您""请"等生疏词

## 工作流程
1. get_scene 取目标场景对白
2. 逐句标注问题类型（书面化/无辨识度/冗余/太直白）
3. propose_edit 提交改写，summary 中给修改前后对照
